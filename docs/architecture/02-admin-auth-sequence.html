Admin Auth, Verification & Privileged Game Creation

Detailed trace of admin credentials validation via bcrypt, 4-hour HS256 JWT minting, Bearer token injection, route protection via get_current_admin, and game creation in PostgreSQL.

Admin Authentication Mechanics Legacy admin credentials are authenticated through POST /api/admin/login (auth.py:578) with OAuth2PasswordRequestForm. Enforces IP/Identifier lockout before comparing against ADMIN_PASSWORD_HASH via bcrypt.checkpw.
Session & Token Handling Tokens are signed using HS256 with JWT_SECRET, valid for 4 hours (auth.py:568). Frontend stores in sessionStorage['admin_token'] and injects as Bearer token via api.js:89 for all mutating routes.
