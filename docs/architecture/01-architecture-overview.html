How does GAMEVERSE run end to end?

Topology mapping Browser clients, Static CDN assets, Vercel Serverless / ASGI entry point, FastAPI middleware pipelines, in-memory route caching, psycopg3 connection pooling, and Supabase cloud Postgres & Auth.

Client Layer (Nodes 1–3) Vanilla JS UI, Three.js 3D visuals, localStorage instant hydration
Application Layer (Nodes 4, 5, 7) FastAPI on Vercel Serverless, GZip, Server-Timing, psycopg3 pool
Cache Hierarchy (Nodes 2 & 6) Local storage zero-latency read + in-process Python 3600s RAM cache
Database & Auth (Nodes 8–10) Supabase Port 6543 Transaction Pooler + PostgreSQL tables + GoTrue
Node count: 10 nodes (Target: 8–12). File links verified against repository code.
