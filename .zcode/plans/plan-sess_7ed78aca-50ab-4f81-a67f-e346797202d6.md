2. **library.html (new dashboard)** — sidebar + topbar + telemetry/radar row + control bar + game grid + all modals. It loads `home.css` and `game-detail.css` (the old page omitted `game-detail.css` — that's why the detail view looked wrong before).
3. Scroll model: home = no scroll at all; library = normal page scroll with sticky sidebar/topbar (nothing fancy).
